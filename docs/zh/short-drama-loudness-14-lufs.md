# 短剧为什么要做到 −14 LUFS（以及为什么不用 ffmpeg loudnorm）

竖屏短剧母带应归一到 **−14 LUFS 整合响度，用一刀恒定增益加 −1 dBFS 峰值限制器**。观众大多
用手机外放观看：短剧分发网络上的爆款实测在 −12 到 −14 LUFS 左右，而 AI 直出的片子通常只有
−20 到 −27 LUFS，低了 6–13 dB，在手机上就是"听不清"。**不要**用 ffmpeg 的 `loudnorm`：
遇到台词加留白的素材它会静默切到动态模式，把安静段和底噪抬高 30–50 dB，干净的素材一压就满是
沙沙声。`dramapack master` 和 `dramapack package` 都按恒定增益处理。

```bash
dramapack inspect ep01.mp4            # 整合响度、真峰值、到目标还差多少增益
dramapack master cut01.mp4 ep01.mp4 --srt 01.srt
```

## 数字

| 素材 | 典型响度 |
|---|---|
| AI 视频直出 / 早期母带 | mean volume −24.7 ~ −27.4 dB |
| 竞品竖屏剧 | mean volume −16.0 ~ −21.5 dB |
| 分发网络爆款 | 约 −12.4 LUFS |
| dramapack 目标 | **−14 LUFS**，峰值上限 −1 dBFS |

在手机上对听 −15.8 和 −14.0 LUFS 之后定了 −14：−15.8 在信息流里已经明显"小一半"。

## 为什么不用 loudnorm

- 单遍 `loudnorm` 是**动态**的：按约 3 秒的窗口把短时响度往目标推，停顿和环境底噪都被推上去。
- 两遍式 `loudnorm ... linear=true` 只是"允许线性"。源响度范围（LRA）大于目标 LRA（11），
  或线性增益会顶破真峰值上限时，ffmpeg 会**静默回退到动态**（第二遍会打印 `normalization_type=dynamic`）。
- 台词加留白的短剧素材 LRA 普遍在 15–20，回退是常态。真实母带实测：安静段 +33 dB，片尾近静音 +49 dB，
  底噪从 −76 抬到 −30 dBFS。

dramapack 的做法：量整合 LUFS → 打**一刀** `volume` 增益（钳在 −24…+20 dB，避免把近静音素材推成
噪声）→ `alimiter` 限在 −1 dBFS。信噪比不变，只动超过上限的峰值。测试里钉死了：三级台阶信号每一级
被抬的量必须相同。

## 按对白量，不按混音量

整合响度有相对门限。铺上配乐床后，安静段的床会被门限放进来，把测量值拉低 2–3 LU（−14.8 的剪辑
铺床后量出 −18.4）。按混音归一会把对白多推 3–4 dB 进限制器。dramapack 用干声对白量，再把增益打到铺床后的混音上。

## 配乐床要在手机上听得见

可选的程序化配乐床（`--bed tension|warm|suspense|dread|hope`）用来盖住拼接缝（实测一处接缝的电平
跳变从 40.8 dB 降到 24.6 dB）。第一版把能量都压在 300 Hz 以下，手机喇叭根本放不出来；现在的床保留中频，
靠**侧链压缩在台词出现时让位**。默认 −6 dB 时，台词期间床对语音频段只增加约 +0.1 dB。
